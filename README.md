# IoT Projects

Collection of IoT projects simulated with Wokwi and built with PlatformIO.

## Projects

### 01 - Blink LED
A simple LED blinking on and off every second.
- **Board:** Arduino Uno
- **Components:** LED, resistor 220Ω
- **Concepts:** digitalWrite, pinMode, delay

### 02 - Traffic Light
A traffic light simulation with red, yellow, and green LEDs.
- **Board:** Arduino Uno
- **Components:** 3 LEDs (red, yellow, green)
- **Concepts:** multiple pins, digitalWrite, pinMode, delay, constants
